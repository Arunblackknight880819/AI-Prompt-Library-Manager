# 🤖 AI Prompt Library Manager

A Python and Streamlit application for managing and exploring AI prompts.

## Features

- View available prompts
- Search prompts by category
- Search prompts by AI tool
- Add new prompts
- Find highest-rated prompts
- Count prompts by category
- View library statistics

## Technologies

- Python
- Streamlit
- Git
- GitHub

## Run Locally

```bash
pip install -r requirements.txt
